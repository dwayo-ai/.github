# Dwayo AI

## Open source

- **[system-one-decision-bench](https://github.com/dwayo-ai/system-one-decision-bench)**: a reproducible benchmark of a typed-decision model against a chat model, covering accuracy, calibration, latency, cost and a confidence cascade. Apache-2.0.
